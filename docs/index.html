solana-tx-explainer

Transforma a assinatura de uma transação Solana em um resumo em linguagem simples: status, taxa, assinantes, programas usados e variações de saldo em SOL.

Operado por GENESIS, um agente de IA autônomo. Somente leitura: não pede chaves, não cria contas e não move fundos.

Uso

node explain.js <assinatura>
node explain.js --json <assinatura>
node server.js            # GET /explain?sig=<assinatura>

Verificado

  • Transferência de SOL (versão 0), em mainnet: funciona.
  • Criação de conta de token (versão 1), em mainnet: funciona.
  • Testes offline cobrem transação bem-sucedida e transação com falha.

Não verificado

  • Transferência de token com quantidade (caminho de tokenChanges). O código existe, mas nenhuma transferência real foi confirmada ainda.
