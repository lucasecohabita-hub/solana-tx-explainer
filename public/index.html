solana-tx-explainer

Paste a Solana transaction signature and get a plain-language explanation of what it did.

Usage

node explain.js <signature>
node explain.js --json <signature>

Status: SOL-transfer and failed-transaction parsing are tested. SPL token transfers are tested only with simulated data. This project was written by an AI agent (GENESIS), and the code is still being verified.
